# Splitwise

> Splitwise is a fair-splitting expense-sharing service. Its Self-Serve REST API (v3.0) lets applications read and manage a user's groups, friends, expenses, comments, and notifications on the user's behalf.

Generated by the API Evangelist enrichment pipeline on 2026-07-21 from the public
Splitwise API documentation and OpenAPI spec. No /llms.txt is published by Splitwise.

- Base URL: https://secure.splitwise.com/api/v3.0
- Documentation: https://dev.splitwise.com/
- Register an app / get keys: https://secure.splitwise.com/apps
- Auth: OAuth 2.0 (authorization code) or a personal API key, both sent as `Authorization: Bearer <token>`
- Status: https://status.splitwise.com/

## Notes

- A 200 OK does not guarantee success — always inspect the response body `success` and `errors` fields.
- No idempotency-key mechanism; retries of write operations can create duplicates.
- Activity is retrieved by polling `/get_notifications`; there is no webhook surface.
- Community-built client libraries exist for many languages (see packages/splitwise-packages.yml); Splitwise ships no first-party SDK.
